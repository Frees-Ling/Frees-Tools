# 架构与服务边界

## 调用链

```text
CLI (Typer) ─┐
             ├─ 业务服务 ─ 文件安全 / 任务 / 配置
TUI (Textual)┘       ├─ Pillow / pypdf
                    ├─ FFmpeg / ffprobe 子进程
                    └─ 本机认证 aria2 JSON-RPC
```

`src/frees_tools/cli.py` 负责参数、非交互入口、JSON 输出及退出码。`tui/app.py` 负责导航、表单、真实文件浏览器、确认弹窗和任务展示；耗时工作由线程执行，不在界面事件循环中同步转码。两种入口调用同一 `services`，服务不导入 Textual。

## 核心组件

- `core/config.py`：platformdirs 用户目录，配置默认值、校验及损坏配置备份。`FREES_TOOLS_HOME` 为显式隔离覆盖。
- `core/tasks.py`：任务数据结构、线程池、取消 Event、SQLite 历史。记录创建 / 开始 / 完成时间、状态、进度、输入、输出、错误及结果。当前进程保留重试调用；跨重启仅保留历史，不序列化 Python 函数。
- `core/files.py`：在目标目录创建临时文件；保护源路径；处理显式覆盖与冲突；服务验证产物后再发布。异常 / 取消清理临时文件，避免把半成品作为最终输出。
- `adapters/engines.py`：按随包、配置、PATH 顺序发现引擎并检查版本，提供系统安装指引。不会自动下载程序。
- `services/images.py`：读取图片信息、EXIF 方向、比例尺寸、透明处理、单图与批量结果。多帧输入要求显式舍弃策略。
- `services/pdf.py`：依次解码图片帧，顺序合成 PDF、纸张与缩放、密码保护及损坏错误，不将所有图片同时解码为像素。
- `services/video.py`：容器与编码参数校验、FFprobe 信息、FFmpeg 结构化进度、取消及结果验证。外部调用为参数数组，不经 shell 拼接。
- `services/torrent.py`：认证回环 RPC、后台引擎生命周期、跨客户端状态、Torrent 路径检查、任务控制和安全删除。

BT 自有持久化任务与转换任务的执行模型不同：转换依附当前客户端，退出取消；aria2 引擎故意继续后台运行，多个 CLI / TUI 客户端连接同一用户状态。`torrent shutdown` 先保存会话再停止，下载断点由 aria2 控制。任务中心不会把不支持暂停的转换包装成可暂停任务。

## 扩展约定

新增功能先实现不依赖 UI 的服务，接收进度回调与取消信号；将明确错误提升为 `ToolError`，再挂 CLI 和 TUI。新增外部引擎必须遵守发现、校验、许可证和安全参数约定。新增配置键更新默认值、校验和迁移策略。测试使用小型自建素材，区分静态参数检查、真实文件处理、本地引擎集成、公共网络与平台实测。

首版不把重试配方持久化为任意代码，也不承诺所有转换支持中途断点恢复。PDF Writer 仍需保留输出对象；大量图片或巨大 PDF 不能视为恒定内存使用。
